PALAK'S BIRTHDAY SURPRISE FOR SALEHEEN

1. Extract this ZIP folder.
2. Open the palak_saleheen_birthday folder in VS Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.

Files:
- index.html: website structure and birthday message
- style.css: styling and responsive layout
- script.js: interactions, photo lightbox and animations
- assets/: the 8 photos you uploaded

The website uses Google Fonts when internet is available. All photos and core functionality are local.
